About This Project

Understanding the methodology, datasets, and technology behind our screening tools

Project Overview

This project implements an Explainable AI (XAI) framework for the early screening of dyslexia and dysgraphia in children. By analyzing reading and writing behavioral patterns through machine learning models, we aim to provide transparent, interpretable, and evidence-based screening tools that can assist educators, clinicians, and parents in early identification.

Early detection of learning disabilities is critical. Research shows that children who receive intervention before the age of 8 have significantly better outcomes. Our system leverages multiple machine learning techniques combined with explainability methods to make the screening process both accurate and understandable.

Project Objectives

Early Detection

Develop screening tools that can identify potential indicators of dyslexia and dysgraphia in children at an early age, enabling timely intervention.

Explainable Predictions

Implement SHAP and LIME-based explanations that make every model prediction transparent and interpretable for non-technical stakeholders.

Multi-Modal Analysis

Analyze both handwriting images (dysgraphia) and reading behavioral data (dyslexia) to provide comprehensive screening capabilities.

Accessible Tools

Create user-friendly web-based tools that can be deployed in schools, clinics, and at-home settings for widespread accessibility.

Explainability Methods

SHAP (SHapley Additive exPlanations)

A game-theoretic approach to explain the output of any machine learning model. SHAP values show the contribution of each feature to the prediction, computed as the average marginal contribution of a feature value across all possible coalitions.

Used for: Both dysgraphia and dyslexia predictions

LIME (Local Interpretable Model-agnostic Explanations)

Explains individual predictions by perturbing the input and observing how the prediction changes. Creates a local linear model around the instance to approximate the decision boundary.

Used for: Dysgraphia image analysis explanations

Feature Importance

Ranking of input features by their overall contribution to the model's predictions, providing a global view of which behavioral patterns are most predictive.

Used for: Model interpretation and feature selection

Datasets

Handwriting samples collected for dysgraphia research, containing images from children with and without dysgraphia diagnoses. Used for training the CNN-based image classifier.

2. UCI Machine Learning Repository - Dyslexia Dataset

Feature-engineered dataset containing reading test results, cognitive scores, and behavioral metrics from children screened for dyslexia.

3. Read & Spell Test (RST) Dataset

Standardized reading and spelling assessment data used to evaluate phonological processing and decoding abilities in children.

4. DYSLEXGIS - Dyslexia and Geography Dataset

Multi-modal dataset combining handwriting samples with cognitive test results for comprehensive dyslexia research.
